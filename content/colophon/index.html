This version of kennethbowen.com was built using GNU Emacs (with web-mode.el) and Bootstrap. Scalable vector icons are also provided by Bootstrap Icons.

The Bootstrap provided responsive design should look nice on most devices.

All files are versioned using the excellent Git distributed version control system — a tool that will forever change your relationship with source control. A simple GitHub workflow deploys changes to Dream Host using rsync over ssh.

Colors are from the Swiss style color picker and the only font used is Questrial from Google Fonts.

Any more content and I should strongly consider using a static site generator.
